### 2. 🎛️ ปุ่มสลับดูกราฟประเภทอื่น ๆ:
- 📊 **กราฟแท่งยอดรวม (หลัก)**: มุมมองเริ่มต้นที่แสดงตัวเลขชัดเจน
- 📊 **กราฟแท่งจำแนกตามช่วงวัย**: เปรียบเทียบ 4 กลุ่มวัย (วัยรุ่น 10-19 ปี เพิ่มขึ้นเร็วที่สุด +111%)
- 📈 **กราฟเส้นแนวโน้ม**: แสดงความชันของการเติบโตในรอบ 5 ปี
- 🍩 **สัดส่วนเพศ**: หญิง 64.2% ต่อ ชาย 35.8% พร้อมข้อสังเกต Gender Paradox

1. **📊 1. กราฟแท่งยอดผู้ป่วย 5 ปี**: กราฟแท่ง, การ์ดสรุปตัวเลขสำคัญ, ตารางสถิติ % YoY, และบทวิเคราะห์เชิงสาธารณสุข
